🌱 Kenapa Aku Ingin Menjadi Web Developer?

Awalnya, aku tertarik dengan dunia web development karena aku ingin tahu bagaimana sebuah website bisa dibuat. Aku sering melihat berbagai website di internet dan mulai penasaran bagaimana semuanya bisa bekerja, mulai dari tampilannya, tombol yang bisa diklik, animasi yang menarik, sampai fitur-fitur yang membuat sebuah website terasa hidup.

Dari rasa penasaran itu, aku mulai tertarik untuk mempelajari bagaimana cara membuat website sendiri.

Menurut aku, dunia web development itu menarik karena kita bisa mengubah ide yang awalnya cuma ada di pikiran menjadi sesuatu yang nyata dan bisa digunakan oleh orang lain. Kita bisa membuat halaman sederhana, mengembangkan fitur baru, mengatur tampilan, sampai membangun sebuah website yang punya fungsi tertentu.

Aku juga suka dengan kenyataan bahwa dunia teknologi terus berkembang. Selalu ada hal baru yang bisa dipelajari dan selalu ada kesempatan untuk meningkatkan kemampuan.

Aku nggak ingin cuma menjadi orang yang menggunakan teknologi, tetapi aku juga ingin belajar bagaimana cara membuat sesuatu dengan teknologi tersebut.

Mungkin sekarang aku masih dalam tahap belajar dasar-dasarnya. Namun, aku berharap suatu hari nanti aku bisa membuat website yang bermanfaat, punya tampilan yang bagus, responsif di berbagai perangkat, dan bisa membantu orang lain.

Buat aku, semua itu adalah alasan yang cukup untuk memulai dan terus melangkah.

📚 Apa Saja yang Ingin Aku Pelajari?

Ada banyak hal yang ingin aku pelajari selama perjalanan menjadi Web Developer. Aku ingin membangun pemahaman yang kuat dari dasar agar nantinya lebih mudah ketika mempelajari teknologi yang lebih lanjut.

Berikut beberapa hal yang ingin aku pelajari dan kembangkan secara bertahap.

 1. HTML

HTML adalah salah satu dasar penting dalam pembuatan website. Aku ingin memahami bagaimana cara menyusun struktur halaman web dengan baik, menggunakan elemen yang sesuai, dan membuat konten website lebih teratur.

Aku juga ingin belajar menggunakan HTML secara semantik supaya struktur halaman yang aku buat lebih mudah dipahami oleh browser maupun teknologi pendukung lainnya.

 2. CSS

Setelah memahami struktur website, aku ingin belajar bagaimana cara membuat tampilannya menjadi lebih menarik menggunakan CSS.

Mulai dari mengatur warna, ukuran teks, jarak antar elemen, layout, sampai membuat tampilan yang responsif untuk berbagai ukuran layar.

Aku ingin belajar menggunakan Flexbox, Grid, dan teknik CSS lainnya agar nantinya bisa membuat website dengan tampilan yang lebih rapi, modern, dan nyaman digunakan.

 3. JavaScript

JavaScript menjadi salah satu teknologi yang ingin aku kuasai karena bisa membuat website menjadi lebih interaktif.

Aku ingin memahami dasar-dasar JavaScript, seperti variabel, tipe data, fungsi, kondisi, perulangan, array, object, dan berbagai konsep lainnya.

Setelah itu, aku ingin belajar bagaimana cara menggunakan JavaScript untuk membuat fitur website, mengolah data, menangani interaksi pengguna, dan memahami cara kerja aplikasi web dengan lebih baik.

Aku tahu JavaScript mungkin akan terasa sulit pada awalnya. Tapi aku ingin terus berlatih sampai bisa memahami logikanya dan menggunakannya dalam proyek nyata.

 4. Git dan GitHub

Aku juga ingin memahami bagaimana cara menggunakan Git dan GitHub dengan baik.

Buat aku, GitHub bukan cuma tempat untuk menyimpan kode, tetapi juga tempat untuk mendokumentasikan perjalanan belajar, mengelola proyek, dan membangun portofolio.

Aku ingin terbiasa menggunakan repository, melakukan commit, memahami perubahan kode, membuat branch, dan mempelajari workflow yang biasa digunakan oleh developer.
